Context

A direct-to-consumer retailer selling vitamins and supplements into Canada. Hundreds of SKUs, repeat purchase built into the category, and an account running Performance Max, Search and Shopping side by side. The question put to the account was not whether it worked - it already did - but how much more spend it could absorb before the return stopped justifying it.

The problem

A profitable account is harder to change than a broken one, because every adjustment risks something that is currently working. This one was returning well on a modest budget, and the ceiling was budget rather than demand: campaigns were sitting in Limited by budget, which means Google was declining to show ads it believed would convert. Scaling into that is the right call only if you can watch the return per added dollar rather than the return overall, because the average hides the moment the next dollar stops paying.

Approach

Spend was increased deliberately rather than all at once, with the account structured so the effect was legible: Performance Max and Shopping carrying the catalogue, Search carrying the terms worth bidding on by name, and the budget-limited campaigns released first because those were the ones turning away traffic. Product feed problems were cleared so the Shopping and Performance Max campaigns had the full catalogue to work with. Reporting was set against cost per conversion and return together, so a rising spend and a falling return rate could be read as one decision instead of two separate alarms.

My role

This account was mine: the structure, the budget decisions, the feed work and the reporting.
